### 1. CASCADE：面向逻辑异常检测的约束感知脚手架分解 ★★★★☆

**原题**: CASCADE: Constraint-Aware SCAffolded DEcomposition for Logical Anomaly Detection  
**作者**: Jinchan Kim, Jinhee Im, Hyunsouk Cho  
**提交**: 2026-11-10 · [论文链接](https://arxiv.org/abs/2611.13820)
**主题**: 工业、多模态  

- **做了什么**: 提出免训练框架CASCADE，用约束特定的视觉脚手架扩展清单式分解，让LVLM针对每条约束适配视觉输入以检测逻辑异常。

- **原文摘要**: Logical Anomaly Detection (LAD) requires verifying whether all category-specific constraints, such as object counts, pairing relations, and measurement ranges, are satisfied by a query image given only a few normal references. Recent LAD methods based on Large Vision-Language Models (LVLMs) formulate this as checklist verification, decomposing the decision into independent textual checks. This decomposition, however, is text-only. Every item still reads the same unmodified query image, so the LVLM must extract different forms of visual evidence from one raw image.
